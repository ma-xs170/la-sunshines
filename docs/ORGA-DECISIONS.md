## Décisions du mode absence (2026-09-21)
- Lint : `npm run lint` n'est pas configuré (Next demande un assistant interactif) : je ne l'ajoute pas ; contrôle de types par `tsc --noEmit`, tests unitaires, tests SQL, e2e, build et Playwright.
- Merge sur main : via un worktree temporaire issu de origin/main (le worktree `la-sunshines-merge` contient des changements d'une autre session, on n'y touche pas).
- Mode public : la base contient `ticketing_mode = native` (réglé depuis l'admin le 2026-09-20 20:12) alors que la consigne dit « bizouk ». Je ne le modifie PAS ; à confirmer au retour.
- Code Bizouk (E) : jamais injecté. `lib/bizoukEmbed.ts` refuse tout ce qui n'est pas Bizouk (scripts en ligne, gestionnaires, javascript:, autres domaines, http, identifiants dans l'URL), n'extrait que l'identifiant numérique, et `BizoukWidget` REGÉNÈRE l'iframe (attributs fixes + sandbox). Pas de CSP `frame-src` globale : la page évènement embarque déjà d'autres iframes (cartes) et une CSP partielle les casserait ; la régénération côté serveur est le contrôle principal. Les codes déjà présents dans le code (lib/bizouk.ts) passent par le même filtre.
- Évènements créés en ligne (E) : créés en BROUILLON (`ticketed_events` + `event_details.title` + lieu + session), capacité provisoire 100 (à régler dans les tarifs), aucun n'est public : la publication reste une action séparée (bouton « Publier » non fourni, étape « validation avec l'équipe » via le support). Pas de page publique /editions pour ces évènements tant qu'ils ne sont pas rattachés à une édition (limite connue, à traiter avec la publication).
- SIRET THE MOUV : mis à jour en base (10425394300013 → 10665995600010) et journalisé (`organizer.siret_fix`). Les pages publiques /mentions-legales et /cgv (et docs/billetterie/LEGAL.md) contiennent encore l'ancien SIRET : NON modifiées (texte légal), à confirmer au retour.
- Bouton « Continuer » des assistants : `onMouseDown` empêche la perte de focus ; sinon la validation au blur décalait la mise en page entre l'appui et le relâchement et le clic était perdu (bug trouvé par le test Playwright).
