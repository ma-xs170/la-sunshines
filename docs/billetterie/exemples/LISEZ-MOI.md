# Exemples de billets PDF

Générés sur le banc de test local avec des **données fictives** (achat de test, participants inventés, secret de signature du banc) :
`billet-exemple.pdf` (un billet = une page), `commande-exemple.pdf` (commande de 2 billets), `billet-exemple-1.png` (aperçu).
Pour en régénérer : lancer le banc (`tests/e2e`) puis `PDF_OUT=dossier node tests/e2e/pdf-sample.mjs`.
